## 🚀 Visão Geral
O Prime Resume é uma plataforma premium focada em ajudar profissionais a construírem currículos de destaque, otimizados para sistemas ATS (Applicant Tracking Systems) e com cartas de apresentação geradas sob medida em poucos segundos. Construído com **Angular**, o projeto traz uma interface de altíssimo nível no modo escuro (Dark Mode), utilizando efeitos de *glassmorphism* e micro-animações para garantir a melhor experiência de usuário do mercado.

## ✨ Principais Funcionalidades
- **🤖 Geração de Conteúdo com IA:** Integração nativa com o Google Gemini para escrever, otimizar e adaptar todo o conteúdo do currículo.
- **🎨 Templates Premium:** Dezenas de modelos profissionais, com e sem foto, meticulosamente desenhados para aprovação em filtros ATS.
- **👁️ Visualização em Tempo Real:** Seu currículo é atualizado na tela instantaneamente enquanto você digita.
- **📄 Exportação em PDF de Alta Qualidade:** Renderização impecável sem quebras indesejadas no layout.
- **🔥 Análise Crítica com IA (Roast):** Uma avaliação sincera e sem rodeios feita por um recrutador IA, apontando falhas e pontos cegos no seu currículo.
- **✉️ Gerador de Carta de Apresentação:** Criação automática de cartas personalizadas baseadas no seu perfil e na vaga desejada.
- **🔗 Importação do LinkedIn:** Faça o upload do seu perfil do LinkedIn em PDF e a IA cuidará de preencher tudo automaticamente.
- **🌍 Internacionalização (i18n):** Suporte completo para múltiplos idiomas (Inglês e Português).

## 🛠️ Tecnologias Utilizadas
- **Framework:** Angular 18 (Standalone Components, Signals)
- **Linguagem:** TypeScript
- **Estilização:** SCSS Puro (Design System construído através de variáveis CSS. *Não utiliza Tailwind* para maior controle da UI)
- **Gerenciamento de Estado:** Angular Signals & RxJS
- **Tradução:** ngx-translate
- **Autenticação:** Google Identity Services (SSO)

## 📦 Como Rodar o Projeto

1. **Clone o repositório**
2. **Instale as dependências:**
   ```bash
   npm install
   ```
3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm start
   ```
   Acesse `http://localhost:4200/`. A aplicação será recarregada automaticamente sempre que você alterar algum arquivo.
